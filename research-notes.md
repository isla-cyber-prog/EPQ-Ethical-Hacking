# Research Notes

## Penetration Testing

Penetration testing is an authorised simulation of a cyber-attack carried out to identify vulnerabilities before malicious attackers can exploit them.

### Advantages

- Identifies weaknesses before attackers do
- Provides practical security testing
- Helps organisations improve security controls

### Limitations

- Can be expensive
- Only represents a snapshot in time
- Cannot guarantee complete protection

---

## Vulnerability Assessments

A vulnerability assessment identifies and prioritises weaknesses within systems and networks.

### Advantages

- Less expensive than penetration testing
- Can be performed more frequently
- Provides broad coverage

### Limitations

- Does not actively exploit vulnerabilities
- May produce false positives

---

## Security Awareness Training

Educates employees about phishing, passwords and safe online behaviour.

### Advantages

- Reduces human error
- Improves organisational security culture

### Limitations

- Requires continuous training
- Human mistakes can still occur
