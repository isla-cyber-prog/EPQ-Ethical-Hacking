# EPQ: Ethical Hacking and Cybersecurity

This repository contains research notes, resources and documentation used during my EPQ project investigating ethical hacking and cybersecurity.

## Research Question

To what extent is penetration testing the most effective way to protect companies from cyber-attacks?

## Objectives

- Understand what penetration testing is and how it is used.
- Investigate other cybersecurity protection methods.
- Compare the effectiveness of penetration testing with alternative defensive measures.
- Examine real-world examples of cyber-attacks and security breaches.
- Consider the financial, legal, and practical implications of penetration testing.
- Draw a conclusion on whether penetration testing is the most effective cybersecurity strategy for organisations.
